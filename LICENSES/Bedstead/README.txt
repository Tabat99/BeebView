Bedstead 3.261
==============

BeebView's SDL bitmap font contains the printable ASCII glyphs (U+0020
through U+007E) derived from bedstead-20.bdf from Bedstead 3.261.

Bedstead is a SAA5050/teletext-style typeface by Ben Harris.
The supplied Bedstead distribution dedicates the work to the public domain
under CC0 1.0 Universal.  See CC0-1.0.txt in this directory.

The original OTF/BDF font files are not required at run time; the small
ASCII bitmap subset used by BeebView is compiled into the SDL frontend.
